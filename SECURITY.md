# Security policy

## Report a vulnerability

Use GitHub's
[private vulnerability reporting](https://github.com/FlyAndNotDown/Rebasely/security/advisories/new).
Do not disclose an unfixed vulnerability in a public issue or pull request.

Include the affected version, impact, and a minimal reproduction using invented
data. Remove credentials, private hosts, workspace paths, and other sensitive
information. Reports are reviewed by the maintainer; there is no guaranteed
response window.

## Supported versions

Security fixes target the latest release. Please update before reporting a
problem, or state why the latest release cannot be used.

See [security boundaries and dependency findings](docs/security.md) for the
application's trust model and known upstream constraints.
